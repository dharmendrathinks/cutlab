# Code of Conduct

CutLab welcomes contributors of all backgrounds and experience levels. Treat others with respect, give constructive feedback, and discuss ideas without attacking people.

Harassment, discriminatory language, threats, sexualized conduct, doxxing, and repeated unwanted contact are not acceptable in project issues, pull requests, discussions, or other project spaces. Do not publish someone else's private information.

Maintainers may edit or remove harmful content, close discussions, restrict participation, or block accounts. Responses should be proportionate to the conduct and protect affected participants. Maintainers are held to the same standards.

To report misconduct privately, use the contact options on [the maintainer's GitHub profile](https://github.com/dharmendrathinks). If no private contact option is available, use [GitHub's abuse reporting](https://docs.github.com/en/site-policy/acceptable-use-policies/github-community-guidelines#reporting-an-issue). Avoid posting sensitive details publicly. Good-faith reports will be handled discreetly; confidentiality cannot be guaranteed beyond the systems used.
