# Roadmap

CutLab aims to make local Android editing understandable, reliable, and open to contribution. This is a priority list, not a release schedule or a commitment to duplicate a proprietary product.

## Next: qualify the foundation

- Physical-device matrix: API 29 through current Android, multiple hardware codecs, long exports and A/V sync.
- Playback profiling on larger projects, memory/thermal measurements, and cancellation/low-storage recovery.
- Accessibility audit: TalkBack, touch targets, contrast, text scaling and keyboard/switch navigation.
- Broader CI device coverage and reliable regression fixtures across ABIs.

## Then: improve everyday editing

- More discoverable timeline and keyframe interactions.
- Better diagnostics for unsupported media, missing sources and insufficient storage.
- Landscape/tablet adaptation and localization readiness.
- Proxy media and more efficient preview/export frame extraction, guided by measured bottlenecks.

## Release readiness

- Maintained signing identity and documented upgrades/backups.
- Complete binary dependency notices and release provenance.
- Repeatable physical-device qualification and signed release distribution.

AI services, accounts/cloud, proprietary content catalogs, third-party draft compatibility and HDR/4K are not planned for the first stable milestone. Proposals should explain the user need, implementation cost, licensing, privacy, and testing approach in an issue.
